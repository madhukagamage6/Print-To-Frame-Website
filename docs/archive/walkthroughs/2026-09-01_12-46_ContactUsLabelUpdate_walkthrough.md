# Walkthrough: Vercel 404 NOT_FOUND Routing Fix

We have resolved the **404: NOT_FOUND** error shown when reloading, hitting back/forward, or directly accessing routes like `https://print2frame.xyz/our-process` or `https://print2frame.xyz/privacy-policy`.

---

## 1. Why the 404 Error Occurred

From your screenshot:
- The error message `404: NOT_FOUND (ID: bom1::...)` is generated by **Vercel's Edge Router**.
- In a Single Page Application (SPA) built with Vite, all pages are client-side components rendered by `index.html`.
- When a user refreshes or navigates directly to `https://print2frame.xyz/our-process`, Vercel searches for a static file named `/our-process`. Because no static file with that name exists, Vercel throws a `404: NOT_FOUND` error.

---

## 2. Solution Implemented

### A. Vercel SPA Routing Configuration ([vercel.json](file:///c:/Users/User/Documents/Github%20repos/Print-To-Frame-Website/vercel.json))
Created `vercel.json` at the root of the project:
```json
{
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}
```
**What this does**: Tells Vercel to route all incoming URL requests (`/our-process`, `/why-us`, `/contact-us`, `/privacy-policy`, `/terms-of-service`, etc.) to `/index.html`. React then mounts, reads the URL path, and renders the correct page immediately with **HTTP 200 OK**.

### B. Multi-Platform Fallback Rules
- **[public/_redirects](file:///c:/Users/User/Documents/Github%20repos/Print-To-Frame-Website/public/_redirects)**: Added wildcard fallback `/* /index.html 200` for Netlify / Cloudflare Pages.
- **[firebase.json](file:///c:/Users/User/Documents/Github%20repos/Print-To-Frame-Website/firebase.json)**: Added SPA rewrite configuration for Firebase Hosting.

## 3. How to Apply the Fix to Your Live Site

Simply commit and push the updated repository to your GitHub branch connected to Vercel (or trigger a new deploy on Vercel):

```bash
git add .
git commit -m "Fix Vercel SPA 404 routing with vercel.json and add SEO assets"
git push origin main
```

Once Vercel automatically deploys this update:
- Direct visits, page reloads, and browser Back/Forward navigation on `/our-process`, `/why-us`, `/contact-us`, `/privacy-policy`, and `/terms-of-service` will load smoothly without any 404 errors.
