Privacy Policy

Effective Date: September 1, 2026 | Print To Frame Pvt Ltd

1. Entity Overview & Application Identity

Print To Frame Pvt Ltd ("we", "our", or "us"), located at No. 58/33 Church Road, Eldeniya, Kadawatha, Sri Lanka, operates the public corporate website https://www.print2frame.xyz and the dedicated cloud fabrication portal https://portal.print2frame.xyz.

This Privacy Policy transparently governs how personal information, business project specifications, and Google user data are collected, processed, securely stored, and protected when you interact with our services, submit fabrication requests, or use our digital portal application.

2. Information We Collect

We collect only the information necessary to provide precision framing engineering and flex printing services:

A. Customer Contact Details

Full name, company/organization name, email address, Sri Lankan phone number (+94), and physical site delivery address.

B. Project Specifications

Banner dimensions (width & height in feet), frame steel gauge, structural wind load tolerances, and customer-uploaded artwork/CAD blueprints.

C. Authentication Credentials

Account identity, profile name, and OAuth authorization tokens obtained via secure Google Sign-In for ERP/portal operations.

D. Technical Telemetry

IP address, browser user-agent, and system diagnostic logs utilized strictly to safeguard service availability and prevent abusive activities.

3. Google API Scopes & User Data Disclosures

When authorized by staff or portal users via Google OAuth, the Print To Frame application requests specific Google APIs to automate order intake and status tracking. Here is the strict, limited purpose for each scope:

Google Drive API (drive.file) Scope: drive.file

Purpose: Used solely to create designated project folders and upload digital print files, artwork vectors, and CAD structural specifications. The application only accesses files created directly by the Print To Frame application.

Google Sheets API (spreadsheets) Scope: spreadsheets

Purpose: Used exclusively to log, track, read, and synchronize real-time fabrication milestones (Act 0 through Act 6 lifecycle steps, payment statuses, and dimension specifications) in the designated operations spreadsheet.

Gmail API (gmail.send) Scope: gmail.send

Purpose: Used exclusively to dispatch automated transactional receipts, order confirmations, and fabrication milestone updates to the client's email address. We do not read, index, or access your incoming messages or inbox history.

Google API Services User Data Policy Compliance

Print To Frame's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. Data Sharing & Non-Sale Commitment

We do not sell, rent, monetize, or trade your personal information or Google user data to advertisers, data brokers, or any commercial third parties.

Information is shared only with verified cloud infrastructure providers (Google Cloud Platform and Firebase) for core hosting and security, and delivery logistics personnel strictly to execute physical frame deliveries.

5. Data Retention, Security & Deletion Rights

All network traffic between your device and our servers is secured using modern Transport Layer Security (TLS/HTTPS). Authentication tokens are securely encapsulated in protected session storage.

To exercise your data privacy rights:

  • You may request complete deletion of your account and files by emailing info@print2frame.xyz.
  • You can revoke Google OAuth permissions at any time via Google Account Security Permissions.
